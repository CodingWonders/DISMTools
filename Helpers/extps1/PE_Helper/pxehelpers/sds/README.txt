 Preparation Steps for the DISMTools System Deployment Services
================================================================

As we are getting started with the DISMTools System Deployment Services, we will
make it easier to set up. But, right now, you will need to do some things to set
it up.

In the file picker that will appear, choose a boot image to add to the server.
These are named "boot.wim". It is recommended that you choose this file from
DISMTools installation media, as they are prepared to work with SDS. If you do
not yet have this media, click Cancel in the picker and the preparation process
will stop. Then, create the ISO file by going to Tools > Create disc image.
You can start this preparation process at any time. We also need the boot image
to copy the required boot files from it.

During preparation, 2 groups will be created on your local machine, or your domain,
depending on whether you are in one; and you will become a member of those groups.
Changing group memberships requires logging off and back on. So, after preparing
your system, you should consider doing so.

As explained earlier, we are working on making the preparation flow easier for
people migrating from WDS and for people who have never used a network deployment
solution. Thus, we would like your feedback.
