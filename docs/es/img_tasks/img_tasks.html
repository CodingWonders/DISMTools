Tareas de imagen

Con DISMTools puedes realizar una variedad de tareas, organizadas según la acción que se aplica a una imagen.

¿Dónde encuentro las tareas?

Todas las tareas están disponibles desde el menú "Comandos".

También tienes acceso a las tareas más importantes en el centro de la pantalla.

Ten en cuenta que estas opciones se habilitan cuando creas un proyecto y montas una imagen. Para realizar esos pasos, consulta la guía Getting started.
