Instalaciones por red

Si deseas desplegar tu imagen de instalación en varios equipos a la vez utilizando un servidor de despliegue, sigue esta guía.

Elige tu proveedor:

Proveedor Versiones compatibles
Windows Deployment Services DISMTools 0.7+
FOG DISMTools 0.7.1+

Esta guía asume que ya has configurado un laboratorio de equipos. Si todavía no lo has hecho, no sabes cómo o sólo usas máquinas virtuales y Wi‑Fi, la documentación de Ayuda ofrece una guía para configurar un laboratorio básico con Hyper‑V.
