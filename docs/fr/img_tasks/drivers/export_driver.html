Exporter des pilotes

Avec DISMTools, vous pouvez exporter facilement tous les pilotes tiers d'une image Windows vers un dossier pour les utiliser ultérieurement dans une autre image. Accédez à cette action via Commandes > Pilotes > Exporter les packages de pilotes...

Compatibilité du système d'exploitation cible

Cette action est compatible avec les plateformes suivantes :

Plateforme Pris en charge ?
Windows 7/Server 2008 R2 ✔
Windows 8/Server 2012 ✔
Windows 8.1/Server 2012 R2 ✔
Windows 10/Server 2016/2019/2022 ✔
Windows 11/Server 2025 ✔

Cette action est prise en charge dans DISMTools 0.3.2 et versions ultérieures

Utilisation

Spécifiez le dossier de destination pour exporter les pilotes (destination d'exportation) et cliquez sur OK.
